Submit:
Tool/platform name and link to tutorial/documentation used
Demonstration: something small created with the tool (project, mock-up, script) with evidence
Reflection (½–1 page):
What does this tool do, and who uses it professionally?
What did you create or try? What was easy/confusing?
How might this tool help in future CS classes or projects?
Submission Requirements
Submit via Google Classroom by the last school day of each month.
One submission accepted per month (work ahead is fine, but pace submissions monthly).
File format: Written work as PDF/Google Doc; slides as PDF or shareable link; code as file or shareable link (Replit/GitHub/CodePen); certificates/screenshots as PNG/JPG/PDF.
File naming: LastName_FirstName_OptionNumber_Month.pdf (e.g., Smith_Jane_Option2_September.pdf)

FAQ

What if I miss a month? You may double up the next month, but all 9 must be finished by May 7th, 2026. No extensions after the final deadline.
